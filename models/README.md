# Model Documentation

## Model Folders

```txt
models/
├── pretrained/   # notes or links for pretrained backbones
└── trained/      # trained KidMood models
```

## Primary Model

- MobileNetV2
- Pretrained on ImageNet
- Frozen backbone during first training stage
- Custom 4-class softmax head for Angry, Fear, Happy, Sad

## Saved Model Path

The final trained model is included in this repository at:

```txt
models/trained/kidmood_mobilenetv2.keras
```

Model file size: approximately 12 MB.

This file was generated by running:

```bash
python src/train.py --raw-dir data/raw --epochs 5 --model-out models/trained/kidmood_mobilenetv2.keras
```

The model is used by:

- `src/evaluate.py`
- `src/inference.py`
- `notebooks/03_evaluation.ipynb`
- `notebooks/04_demo.ipynb`

## Notes

The FER-2013 raw dataset is not committed, but the final trained model is small enough to include directly for reproducible evaluation and demo use.
